# Mecânica dos Solos 2 — estudos para a 2ª EE

Site estático de prática: exercícios corrigidos passo a passo e calculadoras.

- `index.html` — página inicial com os assuntos
- `recalque.html` — recalque por adensamento (Terzaghi)
- `ensaios.html` — ensaios UU, CU, CD, cisalhamento direto e círculo de Mohr
- `fluxo.html` / `fluxo.js` — rede de fluxo: contar canais (NF) e quedas (ND), Δh = h/ND e piezômetro
- `exemplos-recalque.js` / `exemplos-ensaios.js` — exercícios prontos
- `style.css` e os demais `.js` — visual e funcionamento

Todos os arquivos ficam na mesma pasta (sem subpastas).

## Atualizar o site no GitHub

1. No repositório: **Add file → Upload files**.
2. Na pasta `site` do computador, selecione **todos os arquivos** (Ctrl + A) e arraste para a página.
3. **Commit changes**. Em cerca de 1 minuto o site atualiza (use Ctrl + F5).
