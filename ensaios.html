Para tirar c e φ do gráfico

\[ c = \tau \text{ no } \sigma = 0 \qquad \text{tg}\,\varphi = \frac{\tau_2 - \tau_1}{\sigma_2 - \sigma_1} = \frac{\tau - c}{\sigma} \qquad \varphi = \text{arctg}(\text{tg}\,\varphi) \]

Exemplo da aula (CU): c = 3 e o ponto (3; 4) → 4 = 3 + 3·tgφ → tgφ = 1/3 → φ = arctg(1/3) = 18,43°.

Para desenhar a envoltória

Calcule dois pontos e ligue: em σ = 0, τ = c; em σ = 10, τ = c + 10·tgφ. No UU é uma reta horizontal em τ = Cu, e os círculos têm todos o mesmo raio (= Cu).
